`formula-fractions.png` is RapidLaTeXOCR's MIT-licensed test image 6:
https://github.com/RapidAI/RapidLaTeXOCR/blob/main/test_files/6.png

`formula-lines.png` is a locally generated WpfMath image of these six expressions:

```tex
x_1=a+b
x_2=c-d
y=x_1^2+x_2^2
z=xy
u=2x+1
v=3y-2
```

The six-line fixture checks row separation and retention of small ink. Passing
the layout test does not imply every glyph was transcribed correctly. Private
research papers used for exploratory checks are excluded from this repository.
