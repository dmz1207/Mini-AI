# Mini-AI

[English](README.md) | [简体中文](README.zh-CN.md)

**本机离线中英文 OCR 与翻译服务。**

给 [Mini PDF](https://github.com/dmz1207/Mini-PDF)、其他桌面软件和浏览器插件调用。装好功能包后可断网使用，文档不上传，不需要管理员权限、Python、Office、云账号或订阅。

服务 EXE 约 **88 KiB**。识别采用 PP-OCRv6 medium 和 ONNX Runtime；翻译采用 **Hy-MT2-1.8B 1.25-bit** 与专用 STQ 推理内核。翻译权重本身 **461,860,800 字节**，完整单 EXE 约 554 MiB，不增加 Mini PDF 主程序体积。

## 单 EXE，双击即用

下载 **[MiniAI-Portable.exe](https://github.com/dmz1207/Mini-AI/releases/latest/download/MiniAI-Portable.exe)**，放在可写入的文件夹中双击即可。识别、翻译模型及全部运行组件都在里面，无需安装 Python、单独找 DLL 或下载模型。首次运行会校验并解包到旁边的 `MiniAI` 文件夹；以后复用已有文件，并自动修复缺失或损坏的组件，保留其他用户文件。运行期间保留这个文件夹即可；解包内容另占约 610 MiB，更新旧版时先关闭 MiniAI。

独立窗口支持 **打开照片、拖入图片、Ctrl+V 粘贴图片、截图识别**。支持 JPEG、PNG、BMP、TIFF、GIF；大照片自动缩放，并处理 JPEG 拍摄方向。识别结果进入上方可编辑文本框，可修改、选中、复制、保存 TXT 或翻译；勾选“识别后翻译”可自动继续翻译。Alt+S 和“截图翻译”仍使用轻量气泡。TIFF/GIF 读取首帧。

**0.1.1 修复缺 DLL**：翻译内核移除无用 OpenSSL 依赖，OCR 补齐 `msvcp140_1.dll` 等本地运行库。发布前检查所有 EXE/DLL 的依赖，并从空文件夹、仅系统 PATH 的环境实际验证识别和双向翻译。

## 在 Mini PDF 中使用

1. 从[发布页](https://github.com/dmz1207/Mini-AI/releases)下载 **MiniAI-Portable.exe** 放在阅读器旁边；Mini PDF 0.12.1 起可自动检测并在首次使用时准备功能包。也可下载 ZIP，解压形成 `Mini PDF.exe` 和 `MiniAI/MiniAI.exe`，保留包内 models、runtime、licenses 文件夹。
2. 打开 PDF，点上方 **OCR** 或 **翻译**。阅读器按需自动启动服务；若放在其他位置，在“工具 → 加载 MiniAI 功能包”选一次文件夹即可。
3. 选中文字按 **Ctrl+Alt+T**，或右键“离线翻译所选文字”。没选中文字时，自动带入当前页已有文字。方向支持中英互译，长文本自动分段。
4. 扫描页按 **Ctrl+Shift+O**：选当前页、全部或范围 → 识别 → 核对结果 → “添加可搜索文字层” → 保存 PDF。保留扫描图像外观，可选择、搜索和复制文字，也可撤销插入。

识别、翻译时阅读器仍能响应，可随时取消。模型按需加载，空闲 5 分钟释放；阅读器自动启动的后台服务空闲 10 分钟退出。双击 MiniAI.exe 可查看地址、复制连接或停止服务，同一功能包不会重复启动多份服务。

## 给其他软件调用

服务只监听 `127.0.0.1`。运行 `MiniAI.exe --headless --port 0` 可自动选空闲端口。读取本机 `state/connection.json` 中地址和令牌；每次请求需携带 Bearer 令牌。[API 与示例](API.md)。不要上传或分享连接令牌。

提供健康检查、图片 OCR、中英翻译和关闭接口。OCR 返回行文字、置信度与坐标，可供其他软件自行处理页面。浏览器默认禁止访问，需要在 `allowed-origins.txt` 逐行加入插件的准确来源，并同时提供令牌；不默认开放给任意网站。本版没有附带浏览器插件。

## 范围与限制

- OCR 面向印刷中英文、常见单/双栏和轻度倾斜。手写、竖排、复杂表格、低质扫描与数学符号可能有误，不提供数学公式语义识别。
- 1.25-bit 翻译模型通过较强量化缩小体积，科研术语、公式、引用仍须核对，不承诺与大型模型同等精度。
- 本版离线包支持 Windows 10/11 x64，优先 AVX2，同时提供通用 CPU 后备版本，不需要显卡。本次没有发布 macOS、Linux 或 ARM 版本。
- 最多同时接收 2 个计算请求，同一个模型串行运行；繁忙时返回 429。地址、请求体积和浏览器来源有检查，原生库在独立服务中运行。

[测试范围](Verification.md)、[模型来源](Models.md)、[第三方许可](THIRD-PARTY.md)。测试针对具体样本，不代表所有文档无问题。

## 编译

Windows 上运行 `powershell -ExecutionPolicy Bypass -File build.ps1`，使用系统 .NET Framework 4.x 编译器，无 NuGet 依赖。开发者可用 `python tools/fetch_models.py --root .` 获取并校验固定版本资产；最终用户下载完整离线包即可，不需要 Python。

原生内核由 GitHub Actions 编译并实际运行双向翻译测试。历史 GGUF 只调整已知的类型编号描述，模型张量数据不变。程序 MIT，模型和运行时分别遵守各自许可。

## 划词、截图与 Word 联动

- 加载功能包后，PDF 中拖选文字、松开鼠标，就近显示圆角翻译气泡。默认中英自动互译，也可切换日、韩、法、德、西、俄、葡、意及繁体中文。其他语种质量需核对。
- 鼠标移开约一秒收起；按住 Ctrl 临时固定，点击气泡内 Ctrl 可持续固定/取消。支持复制译文。
- Alt+S 变暗屏幕并框选，只对选区执行 OCR 和翻译。识别文字可以修正，选中其中一句可再译，Ctrl+Enter 重译。其他软件已占用 Alt+S 时，仍可点击“截图翻译”。
- 独立打开 MiniAI.exe 可粘贴文字、导入图片或截图翻译，不依赖 Mini PDF。浏览器扩展及其他软件可使用同一本机 API。
- PDF 转 Word 勾选“扫描页先 OCR（MiniAI）”，普通高置信度正文输出为可编辑 Word 文字，复杂公式、不确定区域与图形保留图片。扫描版式为近似重建；不修改原 PDF。
- 推理独立进程、多核 CPU/AVX2、常驻模型与 KV 前缀缓存，并在内存缓存最近 32 个译文；新选区取消旧请求。冷启动和密集整页 OCR 仍需等待，不能保证所有机器实时完成。
