# Mini-AI

[English](README.md) · [简体中文](README.zh-CN.md)

Windows 10/11 x64 离线 OCR 与中英翻译工具，可以独立使用，也能供 Mini PDF、其他软件和浏览器插件通过本机接口调用。

从 [Releases](https://github.com/dmz1207/Mini-AI/releases/latest) 下载 **MiniAI-Portable.exe**，双击即可。模型和私有推理运行时已包含，不需要单独安装 Python、Office 或云端服务。运行时在 EXE 同目录解包并校验；最后一个窗口或阅读器退出后，清理经过校验、属于本软件的运行文件。普通 OCR／翻译结果保存在同级 **MiniAI Results** 文件夹；划词及即时截图翻译不自动保存。下次运行重新解包。未知或被修改的用户文件保留；开发用 `--extract-only` 明确保留解包文件。

## 0.2.0 更新

- 使用 **CTranslate2 4.8.4 + OPUS-MT INT8** 替换原来的 1.8B GGUF/LLM 后端，两套翻译模型未压缩共约 171 MB。支持中英互译、英文转繁体中文；旧多语种 LLM 版本仍可单独下载。
- **极速翻译**使用 Beam 1，逐步显示文字；**高精度翻译**使用 Beam 4，按句显示结果。两档共用模型、分别缓存；高精度搜索更多候选，但不保证每句一定更好。后台预热、常驻模型、文本及分句缓存；新选区取消旧任务，避免旧译文覆盖新结果。
- 推理线程数取 **CPU 物理核心数**，支持处理器组。官方运行时自动选择受支持的 AVX2／AVX-512，不强行启用不支持的指令。
- 检测到兼容的 **NVIDIA CUDA** 环境后自动尝试加速，初始化或推理失败时回退 CPU。默认包未包含体积较大的可选 CUDA／cuBLAS 库；此后端不支持 AMD／Intel 显卡加速。界面显示实际使用的后端。
- 等待翻译期间气泡保持显示，完成后保留 8–20 秒阅读时间。鼠标悬停可继续阅读，按 Ctrl 固定，点击 Ctrl 解除，Esc 关闭；可以选择、复制译文，展开“原文”后选择更小范围翻译。

## 使用

输入或粘贴文本，选中需要翻译的部分，也可 Ctrl+Enter 翻译。支持打开／拖入照片、粘贴图片、截图识别；OCR 结果可以编辑、选择和复制。Alt+S 可截图翻译（快捷键未被其他软件占用时）。“图片翻译”在对应文字区域覆盖译文，可切换原图、复制文字／图片、保存 PNG；“提取文字”打开可选择复制的侧栏。极速截图／照片使用 PP-OCRv6 tiny（新增模型约 6.35 MB）；高精度使用 medium，切换时重新识别。PDF 搜索文字层和转 Word 默认仍用 medium。

完整 EXE 放在 Mini PDF.exe 同目录即可发现，也可在阅读器里手动选择该 EXE。**Mini PDF 0.12.3** 增加对应的流式气泡、所选输入范围翻译与后台预热；仍兼容已解包目录。

本机接口只监听 127.0.0.1，使用随机令牌；浏览器来源默认拒绝，需主动设置允许列表。图片、文档和翻译内容不上传，参见 [API.md](API.md)。多个窗口和阅读器共用服务，最后一个客户端释放后退出，避免其他窗口仍在使用时提前清理。

完整 EXE 实测约 **293 MiB**，包含两档 OCR、两个翻译方向和私有运行时，旧版约 554 MiB。

## 实测与限制

开发机 i7-8565U、4 个物理核心、AVX2：预热约 2.2 秒，测试短句经流式接口约 0.04–0.05 秒完成，两句学术文本约 0.13–0.15 秒；同一张三行深色截图，tiny OCR 约 0.35 秒，medium 约 6.6 秒；用户提供的中英文截图 tiny 约 0.3–0.7 秒。解包、加载和翻译另需时间，不保证任意图片都两秒完成。缓存命中单独统计。这些是样例实测，不是所有文献的速度或准确率保证。

小模型以部分翻译质量换取速度；专业术语和复杂句仍可能需要修订。没有独显可供本地实测，不能据此宣称已验证所有显卡。模型来源、校验值、测试范围和许可见 [Models.md](Models.md)、[Verification.md](Verification.md)、[THIRD-PARTY.md](THIRD-PARTY.md)。

源码、下载、模型转换和构建文件均位于项目文件夹内；源码包不包含模型、缓存、访问令牌或私人文档。
