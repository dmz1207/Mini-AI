# Mini-AI

Windows 离线 OCR、公式识别与翻译工具。下载 [正式版 MiniAI-Portable.exe](https://github.com/dmz1207/Mini-AI/releases/latest)，双击即可运行；模型已包含，不需要 Python、浏览器内核或 Office。支持 Windows 10/11 x64，需要系统 .NET Framework 4.8。

主界面保留原文、译文和常用操作，照片可以拖进窗口。菜单可打开照片、粘贴截图、提取文字。语言菜单列出模型支持的 38 个目标选项；自动方向用于中英互译，极速与高精度共用 Hy-MT2 模型。

- **Alt+S**：框选截图，离线识别后直接在图片上显示译文。
- **Alt+Shift+S / 截图公式**：框选单个公式，查看预览、修改 LaTeX，然后复制 MathML 到支持该格式的 MathType，或复制 LaTeX、PNG。识别出的多个公式可以分别选择，切换时保留手动修改。粘贴后请核对结果。
- **划词翻译**：选中文字后显示小气泡，可拖动、缩放、滚动和复制。在原文区再次选中一部分，就翻译那一部分。Ctrl 或固定按钮保留气泡，Esc / × 关闭。
- **气泡调整**：拖住顶部空白处或移动标记即可移动，四条边和四角均可缩放。截图十字使用亮绿色和深色描边，便于在深浅背景上定位。
- **Mini PDF 调用**：在其离线 AI 菜单选择这个 EXE；模型在后台准备，同一服务供多个本地窗口复用。

默认 CPU 推理，按物理核心数分配线程。打开软件后低优先级准备模型，实际翻译时恢复正常优先级；流式显示结果，复用模型、提示词缓存及结果缓存，取消旧选区后优先处理新请求。可选 GPU 运行时的使用方式见 [Models.md](Models.md)。

单文件包使用 Windows 自带压缩 API 和可逆数据重排，解压后逐个校验原文件哈希，不修改模型权重。正常退出且最后一个调用者释放服务后，自动清理自己解压的运行文件；明确生成的识别、翻译结果留在 EXE 旁的 **MiniAI Results** 文件夹。即时翻译不落盘，用户放入解压目录的额外文件会保留。

公式、复杂布局、低清图片和专业术语仍可能识别或翻译错误。不支持的公式语法保留 LaTeX 供修改；不要把自动识别结果当成已核验的数学结论。实际测试范围见 [Verification.md](Verification.md)。

开发构建与接口说明见 [README.md](README.md)、[API.md](API.md)。许可证见 [THIRD-PARTY.md](THIRD-PARTY.md)。
